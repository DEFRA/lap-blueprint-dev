# Projects

Projects is a directory of completed projects, including how each one was delivered and evidenced. Over time, each project page will capture supporting artefacts such as PRDs, HLDs, LLDs, architecture decisions, benefits realisation data, metrics, measurable outcomes, and agent configurations.

## Request further information

If you would like to learn more about any of the projects featured within the LAMAI Blueprint including architectural decisions, delivery approaches, AI-enabled modernisation techniques, lessons learned, or reusable assets, please contact the AI Enablement Team.

Email: LAP-AIEnablement@defra.gov.uk

The team can provide:

- Additional project information.
- Modernisation best-practice guidance.
- Information on available AI agents.
- Support for similar transformation initiatives.
- Access to relevant artefacts, where appropriate.
