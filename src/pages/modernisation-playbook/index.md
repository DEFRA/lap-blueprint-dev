## Recommended modernisation journey

Most projects follow these steps:

1. Understand the existing application
2. Assess technical and business risks
3. Reverse engineer where necessary
4. Define the target architecture
5. Design the solution
6. Build and test changes
7. Deploy and transition to support
8. Capture lessons learned
