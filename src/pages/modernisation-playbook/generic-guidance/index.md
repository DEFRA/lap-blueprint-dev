# Generic Guidance

This guidance describes how the Legacy Application Programme (LAP) uses AI-assisted tooling to modernise legacy applications. It supports two phases that teams can use independently or together: reverse engineering to create an evidence-based Product Requirements Document (PRD), and re-engineering to design, build and deploy a modern replacement.

Start with the Overview for the delivery context, team and stakeholder roles. Then follow the phase that applies to the work, using the considerations guidance to address information governance, personal data, AI output quality and cost before processing application material.
