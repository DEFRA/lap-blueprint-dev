# GitHub Access

Getting GitHub access in DEFRA covers account setup, joining the right DEFRA organisation, and requesting the correct level of repository access for your role.

The official process and contact routes are maintained in the DEFRA Software Development Standards:
[GitHub access (official guidance)](https://defra.github.io/software-development-standards/processes/github_access/).

## Account requirements

Before requesting organisational access, your GitHub account must have:

- two-factor authentication (2FA) enabled
- your full name populated in your GitHub profile

You can use an existing account or create one specifically for DEFRA work.

## Access routes available

Depending on what you need, access is usually granted in one of two ways:

- organisation membership for broader participation in an organisation
- outside collaborator access for specific repository-level access

DEFRA work is hosted across multiple organisations, including DEFRA, Defra Data Science Centre of Excellence, defra-design, and aphascience.
